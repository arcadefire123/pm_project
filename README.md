# PM 견인 데이터 기반 'PM 전용 주차구역' 최적 입지 추가 선정 제안

**Optimizing Personal Mobility Parking Zones in Seoul via Towing Hotspot Cluster Analysis**

첨단교통검지체계론(Advanced Fundamentals of Traffic Detection System) 수업 팀 프로젝트

## 프로젝트 배경

전동킥보드(PM) 이용 급증으로 불법 주차 및 견인 문제가 심각해지면서 보행자 안전을 위협하는 요인으로 대두되었습니다. 이에 기존 PM 주차 인프라가 실제 수요를 얼마나 충족하고 있는지 검증하고, 데이터 기반의 개선안을 제시하고자 본 프로젝트를 진행했습니다.

## 사용 데이터

- 서울시 전동킥보드 견인 현황 (2025년, 서울열린데이터광장)
- 서울시 전동킥보드 주차구역 현황 (2025.08.22 기준, 서울열린데이터광장)

## 분석 과정

### 1. 데이터 전처리
6개월 단위로 나뉜 2025년 1~6월, 7~12월 견인 현황 파일에서 월별 데이터를 추출한 뒤, 12개 월별 파일을 하나의 2025년 전체 견인 현황 데이터로 결합했습니다.

### 2. 지오코딩
견인 데이터에는 견인 장소의 주소명만 기재되어 있어, 실제 위경도 좌표를 얻기 위해 지오코딩을 수행했습니다. 지오코딩에 실패한 일부 행은 수가 많지 않아 주소를 직접 검색해 좌표를 입력했습니다.

### 3. DBSCAN 군집분석 (수요 핫스팟 도출)
단순 점 데이터를 의미 있는 수요 집합(Hotspot)으로 변환하기 위해 밀도 기반 클러스터링 알고리즘인 DBSCAN을 적용했습니다. 클러스터 개수를 사전에 정할 필요가 없고, 불규칙한 밀집 지역도 잘 찾아내며, 노이즈 데이터를 걸러낼 수 있다는 점에서 K-Means보다 적합하다고 판단했습니다.

**파라미터 설정 근거**

| 파라미터 | 값 | 근거 |
|---|---|---|
| 반경(eps) | 30m | GPS 오차 범위(도심 5~15m), 라스트마일 보행 접근성(약 50m), PM 주차구역 물리적 길이(5~10m)를 종합적으로 고려 |
| 최소 샘플 수(min_samples) | 10건 | 1회성 우발적 주차를 배제하고, 연간 10회 이상 반복된 상습 문제 구역만 유효 수요지로 정의 |

### 4. 공급-수요 미스매치 분석
추출된 수요 핫스팟과 기존 주차장 간의 최단 거리(Nearest Neighbor Distance)를 계산해 개선이 시급한 지점을 식별했습니다.

**보행 임계치: 200m** — 성인 평균 보행속도(1.0~1.3m/s) 기준 약 2.5~3분 소요 거리로, PM 라스트마일 특성상 이 이상 걸어야 한다면 이용자 효용이 크게 저하되어 불법 주차를 유발하는 임계점으로 설정했습니다.

### 5. Folium 시각화
견인 밀집도(Heatmap)와 공급-수요 불일치 지점을 한눈에 파악할 수 있는 인터랙티브 지도를 생성했습니다.

- 🔵 파란색 점: 기존 공식 주차구역 (Supply)
- 🔴 히트맵: 견인 밀집도 — 빨강(높음) → 초록(낮음) (Demand)
- ⭐ 흰 별 마크: 신규 주차구역 추천 지점 — 수요는 높지만 200m 이내 기존 인프라가 없는 서비스 사각지대 (Solution)

## 결과

- 서울 전역에서 **반경 30m 내 연 10건 이상** 견인이 발생한 상습 불법주차 핵심 거점 **213곳** 도출
- 이 중 **71.8%(153곳)**가 기존 주차 인프라로부터 보행 임계 거리(200m)를 초과해 위치
- 해당 153개 지점을 PM 주차구역 최우선 신설 후보지로 제안

## 활용 방안

본 분석 방법론은 범용성이 높아, 타 지역의 PM 데이터와 교통 특성에 맞게 보행 임계치·DBSCAN 파라미터를 조정하면 즉시 적용 가능합니다.
